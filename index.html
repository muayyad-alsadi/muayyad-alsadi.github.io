As of October 2026

Runs standard Compose files (docker-compose.yml) on Podman, Red Hat’s daemonless, rootless container engine. Teams keep the stacks they already have and gain Podman’s security model: no root-owned daemon, containers running as unprivileged users. It now lives in the official containers organization, beside Podman, Buildah and Skopeo.

Upstream

Upstream work runs from a new feature to the patch a release was waiting on. Patches sent by mail, including NGINX, Fedora, WINE and GNOME, are not all GitHub pull requests.

  • Docker. Years of contributions, always in the plural. An early proposal for multi-stage builds: a flat switch-root to a sub-image (moby #15271, August 2015), closer to the form Docker shipped in 17.05 than Solomon Hykes’ nested IN { } / PUBLISH (#7115). The point was to stop shipping compilers and build-time dependencies. Also a clear error when a host volume path does not start with / (#27985, 2016), and dnf download support for busybox in Fedora-Dockerfiles #171.
  • wasmtime-py, Bytecode Alliance. Made copying data between Python and WebAssembly linear memory 400× faster, replacing per-byte access with a direct memmove (#134, merged 2023). Proposed a further 7× faster call path (#139, open). Written up on Medium; the same bottleneck was reported to Wasmer.
  • NGINX. Weighted ip_hash (2012). The docs said ip_hash could not be combined with weight. Ticket #144 carried a working algorithm, and Maxim Dounin added weight support in NGINX 1.3.1. It had been called impossible on the mailing list.
  • Fedora / RHEL, Red Hat. Proposed and implemented the MediaRepo feature. Four PackageKit patches: 277490d, 5d1dede, 9ae160e, 97ba7c6, and the freedesktop copy. Yumex. A working sysctl.d. PulseAudio: stopped a denial of service caused by flooding the logs.
  • Podman. Tests for parallel execution and networking (#2570) and docs pointing to third-party Compose tools (#2981), both merged in 2019.
  • DuckDB. PostgreSQL compatibility: simulated datallowconn / datistemplate in pg_catalog.pg_database (#22302, 2026).
  • scikit-learn. Upstream contribution (#10033, 2017).
  • Meilisearch. Issue #6365 (May 2026): documents with no embedding vector were scored as zeros, so cosine ranking could place them above real matches. The project called it a valid case for retrieval with optional media and set out a fix.
  • WINE. Many patches to the Windows runtime on Linux, including bug 7150.
  • GNOME. Patches for gnome-terminal and notification.
  • XML and XSLT. DocBook at xml.org (OASIS). Publican XSLT fixes (Red Hat). gnome-docs XSLT fixes.
  • Xapian. Fixes to the C++ search library (ticket 355). Whoosh. Contributions to the Python search engine, used in thawab. OpenStack. Contributions to cloud infrastructure.
  • Bootstrap. Fixed fluid thumbnails that broke after the first row (issue), and RTL support shipped as Bootstrap RTL for v2 and v3, plus rtl-xtra-rtl.css, a direction-neutral stylesheet.
  • Yii. Lazy sessions to limit denial of service. Caching AuthManager to stop recursive queries. CClientScript ordering. Dynamic partials so blocks can be left out of a fully cached page. I brought the Redis extension up to date. yii-EClientScript: combine and minify CSS and JavaScript with strong hash filenames based on mtime, including precompressed gzip for NGINX.
  • Also. keras-ocr #39 (2020). open-headunit #1058, open-source Android Auto, a USB-service crash. jquery.smartbanner #10, Chrome on iOS. A Unicode fix in the Python LTI library (IMS LTI). The Flatpak of Othman on Flathub.
